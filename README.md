Laboratório isolado com três conceitos de Hero. Não altera a landing nem a plataforma.

Servir: `python -m http.server 5400` dentro desta pasta, depois abrir http://localhost:5400/

| Conceito | Caminho | Tema nativo |
|---|---|---|
| Índice / comparação | `index.html` | dark |
| A · Cinematic Command Center | `concept-a/index.html` | dark |
| B · Editorial Future | `concept-b/index.html` | light |
| C · Interactive Intelligence | `concept-c/index.html` | light |

Capturas: `shots/` (12 PNG: 3 conceitos × desktop 1440 / mobile 390 × dark / light).
